# osprey-stratify

For CS 4241: Webware, in collaboration with Osprey Software, our 5-person team
developed a private school benchmarking platform for school administrators to
compare their school's metrics against similar schools. I served as lead
developer, maintaining the codebase, performing code reviews, and providing
guidance to team members.

The web app contains several multi-step forms for school administrators to input
their school's data, which is then stored in a PostgreSQL database. The platform
provides comprehensive data analysis and visualization features, allowing users
to generate reports and compare their school's performance against peer
institutions.

As security and privacy were paramount, we implemented robust authentication and
authorization mechanisms via Auth0 and role-based access control policies.
