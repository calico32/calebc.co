# hanover-ibank

For CS 3733: Software Engineering, our team collaborated with Hanover Insurance
to create a modern internal content management system to catalog and organize a
growing collections of thousands of web links and documents. As lead developer, I
oversaw the 10-person team in the development of the system built on the PERN
stack (PostgreSQL, Express, React, Node.js) and integrated AI features to
enhance document search and retrieval.

We applied Agile development practices, including daily stand-ups and sprint
planning/retrospectives, as well as extreme programming techniques like pair
programming and test-driven development.

Deployment was handled via Railway and a CI/CD pipeline from our GitHub
repository, ensuring smooth updates and maintenance. We received positive
feedback from Hanover Insurance stakeholders who appreciated improved user
experience, faster search capabilities, integration with existing systems, and
the overall efficiency of the new platform during a live demo.
